# Sistema de reservaciones y control de paquetes

**Jimena Morales Gómez**

## Descripción

Este proyecto busca llevar un mejor control de las reservaciones de un cuarto que utilizan diferentes personas para atender a sus clientes.

El sistema permite consultar los horarios disponibles, registrar reservaciones y evitar que dos personas aparten el cuarto en el mismo horario.

También permite llevar el control de paquetes de 5 y 10 usos, consultar cuántos usos le quedan a cada persona y saber cuándo un paquete se ha terminado.

## Alcance

El proyecto se enfoca principalmente en:

- Reservaciones del cuarto.
- Consulta de horarios disponibles.
- Evitar empalmes de reservaciones.
- Registro de paquetes de 5 y 10 usos.
- Consulta de usos disponibles.
- Consulta de reservaciones.

No incluye inventario, contabilidad ni la administración completa del negocio.
